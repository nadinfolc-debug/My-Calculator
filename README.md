# Бюджет нейрокреатора

Локальный сайт для учёта заказов и расходов нейрокреатора: доходы по дням, подписки на нейросети, продвижение, интернет и чистая прибыль за месяц.

Данные хранятся только в браузере (`localStorage`). Сервер и регистрация не нужны.

## Страницы

| Файл | Назначение |
| --- | --- |
| [index.html](index.html) | Приветственный лендинг и быстрый расчёт месяца |
| [creator-budget.html](creator-budget.html) | Полный учёт заказов, расходов и отчётов |

## Как открыть

1. Склонируйте репозиторий или скопируйте папку проекта.
2. Откройте `index.html` в браузере (двойной клик или «Open with Live Server»).
3. Нажмите **Открыть учёт**, чтобы перейти к журналу заказов.

Можно открыть `creator-budget.html` напрямую.

Локальный HTTP-сервер (необязательно):

```bash
python -m http.server 8080
```

Затем откройте http://127.0.0.1:8080/

## Возможности учёта

- Заказы с датой, названием и суммой
- Итоги по дням и по выбранному месяцу
- Расходы: нейросети, соцсети, интернет
- Отчёт за период
- Светлая и тёмная тема
- Автосохранение в браузере
- Экспорт и импорт JSON, резервная копия

## Приватность

Приложение не отправляет данные в сеть. Очистка данных сайта в браузере удалит учёт. Для архива используйте **Экспорт JSON**.
